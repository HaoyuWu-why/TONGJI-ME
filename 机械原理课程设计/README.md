# 机械原理课程设计

四自由度机械臂的运动学分析与 Simscape Multibody 仿真资料，包含五个 STEP 零件、Simulink 模型、MATLAB 符号反解脚本、设计说明书和机械臂运动演示。

## 内容与功能

- 使用四个转动副构成空间机械臂，完成末端位置与姿态控制。
- MATLAB Function 模块计算关节角，模型通过关节反馈与 PID 控制驱动机械臂。
- `Function.m` 使用符号方程推导平面二连杆的逆运动学关系。
- 说明书展示机械臂结构、运动学公式、模型连接和运动过程截图。

## 软件环境

- MATLAB R2023a：模型记录的保存版本；更新版本需自行检查兼容性。
- Simulink、Simscape、Simscape Multibody：打开并运行机械臂模型。
- Symbolic Math Toolbox：运行 `Function.m` 中的 `syms`、`solve` 和 `subs`。
- STEP 兼容 CAD 软件：可选，用于查看 `1.stp` 至 `5.stp`；零件导出工具记录为 Autodesk Inventor 2023。
- Word 或其他 DOCX 阅读器、MP4 播放器：查看设计说明和演示。

## 打开与运行

1. 下载整个子项目，保留五个 STEP 文件。
2. 在 MATLAB 中将当前文件夹切换到 `模型与脚本`，打开 `mechanical_arm.slx`。
3. 原模型中的五个实体块仍记录旧电脑的几何文件路径。逐一打开名为 `1`、`2`、`3`、`4`、`5` 的 File Solid 块，在 Geometry 的文件选择项中重新选择本目录对应的 `1.stp` 至 `5.stp`，保存模型。仅调整文件引用。
4. 更新模型，确认没有缺失几何文件或工具箱的错误，然后运行仿真，在 Mechanics Explorer 中观察运动过程。
5. 如需查看符号反解推导，在同一目录单独运行 `Function.m`。该脚本生成符号表达式，不自动向仿真模型传入参数。

## 验证与资料差异

- 运行前确认五个几何文件均已加载、四个转动副连接完整。
- 运行后检查关节角、末端轨迹与姿态，确认运动期间不存在求解器错误，并与演示视频比较。
- 说明书给出的设计目标为末端位置 `(1.5, 1.2, 1.3) m`、姿态角 `60°`，在 `0–5 s` 运动、`5–10 s` 保持。
- 原模型与说明书存在参数差异：模型内反解函数使用 `L1 = L2 = L3 = 0.8`，且底座角公式为 `atan(-z/x)`；说明书中的长度记述和 `Function.m` 的 `atan(z/x)` 与之不同。复现实验时应对照实际模型、坐标轴定义与说明书核对，不能直接把说明书目标视为已验证结果。
