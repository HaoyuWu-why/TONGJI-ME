# 控制工程基础 MATLAB Simulink 仿真实验

本项目整理控制工程基础课程中的 MATLAB 与 Simulink 仿真实验，包含原始拓扑模型、高精度固定步长仿真脚本、真实仿真结果和匿名实验报告。模型结构与课程实验要求保持一致，结果图由 MATLAB R2023a 和 Simulink 直接生成。

## 实验内容

- 比例、积分和一阶惯性环节的时域响应
- PI、PD 和 PID 控制环节的阶跃响应
- 不同阻尼比下的二阶系统响应
- 二阶系统峰值频率、截止频率、Bode 图和 Nyquist 图
- 串联超前校正、速度反馈校正和复合校正

## 运行环境

- MATLAB R2023a
- Simulink
- Control System Toolbox

## 复现实验

1. 将 MATLAB 当前文件夹切换到本项目根目录。
2. 运行 `matlab/run_simulations.m`。
3. 脚本自动打开 `models` 中的模型，以固定步长运行全部实验，并将输出保存到 `results`。

脚本按实验对象选用 `0.001 s`、`0.0005 s` 或 `0.0001 s` 的固定步长。频率扫描单个频率点运行 90 秒，并使用末四个完整周期计算稳态幅值和相位。

## 结果说明

- 示波器结果采用黑色背景和高对比度曲线。
- 峰值频率实测值为 `0.707 rad/s`，理论值为 `0.707107 rad/s`。
- 截止频率实测值为 `1.272 rad/s`，理论值为 `1.272020 rad/s`。
- 仓库保留关键扫频数据、汇总数据和结果图；体积较大的完整时序 CSV 文件由脚本运行时重新生成。
