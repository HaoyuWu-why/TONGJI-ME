## 目录约定

- 每门课程或独立设计占用一个顶层目录。
- 每个项目必须附带 README，说明功能、软硬件环境、构建步骤与验证方法。
- 仅提交可复现工程所需的源码、约束、IP 配置和脚本；构建产物、仿真临时文件、日志及第三方可执行工具不纳入版本控制。
