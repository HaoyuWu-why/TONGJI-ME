# TONGJI ME

同济大学机械设计制造及其自动化专业的课程资料与项目归档。

## 当前项目

| 项目 | 说明 |
| --- | --- |
| [电子电路设计](./电子电路设计/) | 基于 DMZ-EG4S20 开发板的 DDS 波形发生器，包含 FPGA RTL、约束、DDS IP、仿真脚本与串口参数发送工具。 |
| [机械原理课程设计](./机械原理课程设计/) | 四自由度机械臂的运动学与 Multibody 仿真，包含 STEP 零件、Simulink 模型、MATLAB 脚本、设计说明书及演示视频。 |

## 目录约定

- 每门课程或独立设计占用一个顶层目录。
- 每个项目必须附带 README，说明功能、软硬件环境、构建步骤与验证方法。
- 仅提交可复现工程所需的源码、约束、IP 配置和脚本；构建产物、仿真临时文件、日志及第三方可执行工具不纳入版本控制。

## 使用说明

课程资料可能受课程要求、版权或个人信息限制。本仓库当前公开；发布或共享子项目时，应移除个人信息，并检查资料是否适合分发。
